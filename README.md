# 🧠 CNN Image Classification (Jupyter Notebook)

## 📌 Project Overview

This project demonstrates **Image Classification using Convolutional Neural Networks (CNN)** implemented entirely in a **Jupyter Notebook**. It covers data preprocessing, model building, training, evaluation, and prediction in a single file.

---

## 🚀 Features

* End-to-end implementation in Jupyter Notebook
* Image preprocessing and normalization
* CNN model building using TensorFlow/Keras
* Model training and evaluation
* Visualization of accuracy and loss
* Image prediction

---

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* TensorFlow / Keras
* NumPy
* Matplotlib
* OpenCV (optional)

---


## ⚙️ Installation

1. Install required libraries:

```
pip install tensorflow numpy matplotlib opencv-python
```

2. Open Jupyter Notebook:

```
jupyter notebook
```

3. Run the notebook:

* Open `cnn_image_classification.ipynb`
* Run all cells step by step
